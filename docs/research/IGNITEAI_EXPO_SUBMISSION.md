# IgniteAI Expo submission research

Checked October 1, 2026. Official source: [IgniteAI Expo 2026](https://igniteaiexpo.org/).

## Verified requirements

- Applications close October 1, 2026, 11:59 PM Pacific. Zoom interviews occur October 4, 9:30–11:30 AM Pacific, with check-in at 9:30. The project brief's October 4 deadline concerns the demo, not application submission. [Timeline](https://igniteaiexpo.org/#timeline)
- Judges assess a functioning live demonstration, implementation understanding, practical value, and creativity. Explain AI tools used. Keep a backup recording. [Judging](https://igniteaiexpo.org/#judging)
- Summaries must explain the project clearly. Original extensions matter; tutorial replication generally fails eligibility. Each student gets one annual entry. [Rules](https://igniteaiexpo.org/#rules)
- No explicit unfinished-project exemption appears. A working technology project and live interview demonstration are required. [Rules](https://igniteaiexpo.org/#rules)

## Selection uncertainty

The supplied form has one track selector. The website describes one annual entry, but does not separately clarify cross-track judging. Select the strongest fit; do not assume multiple entries are permitted. The website's application link currently points to email, so form character limits were not verified.
